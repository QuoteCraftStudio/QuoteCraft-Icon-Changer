# Changelog

Notable changes to **Super Easy Icon Changer** are documented here.

## 1.0.1 — 2026-11-02

- Added the explicit responsibility-and-terms checkbox on the website version before opening the Icon Changer.
- Added clear links to the existing website Privacy Notice and App Terms.
- Kept icon selection, shortcut creation, and all existing file-handling features unchanged.
- Part of the same consent-and-links update applied to the QuoteCraft Studio app collection.

## 1.0.0 — 2026-11-02

**Initial documented source release** of the standalone HTML edition currently hosted by QuoteCraft Studio.

- Select icon images from files or a user-selected folder, search filenames, and preview images.
- Generate icon styles and export Windows ICO files.
- Preserve supported Internet shortcut URLs and export a ZIP with the `.url` and matching `.ico`.
- Inspect supported APK package information without inventing app-launch URLs.
- Add clear status messages and safeguards for unsupported local app launches.
- Document desktop, mobile and browser limitations.

Version 1.0.0 describes the first GitHub source publication; it does not indicate a newly installed Android or Windows application.
